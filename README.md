# Travel Agency Management System

A console-based Travel Agency Management System developed using java and Object-Oriented Programming (OOP) concepts. The project helps manage trips, customers, and reservations efficiently.

---

## Features
- Browse available travel packages
- Book and cancel trips
- Manage customers and reservations
- Search trips by destination
- Admin control panel
- File handling support

---

## OOP Concepts Used
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

---

## Technologies Used
- C++
- OOP
- File Handling
- Data Structures
